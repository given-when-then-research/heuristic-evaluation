# Gherkin Match Pairs App

A simple **React** tool to manually review and validate **Gherkin–Step Definition pairs** from your dataset.
Used to support the manual evaluation stage of your **BDD dataset pipeline**.

---

## Requirements

* **Node.js 24.1.0**
* **npm 10+**

> Tip: if you use **nvm**, run `nvm use 24.1.0`.

---

## Setup

```bash
# Use the correct Node version
nvm use 24.1.0

# Install dependencies
npm install

# Start development server
npm run dev
```

Then open:
👉 `http://localhost:5173`

---

## Input Dataset

Example file: `../../dataset/exploitation-to-evaluation.json`
